## Instructions to Compile and Run Programs

All programs in this repository are written in Bash shell scripting and can be run using **Git Bash** on Windows, or standard Linux/macOS terminals.

### 1. Running the Greeting Script (`exercise-03`)
```bash
cd exercise-03
bash greet.sh
```
* **Sample Input:** Enter your name when prompted, or press <kbd>Enter</kbd> to test empty input handling.

### 2. Running the Interactive Utility Menu (`exercise-07`)
```bash
cd exercise-07
bash menu.sh
```
* **Menu Options:**
  - `1`: Personalized user greeting
  - `2`: Addition of two integers
  - `3`: Check whether an integer is Even or Odd
  - `4`: Exit program
